Welcome to the Practicals

This site hosts practical exercises and supporting materials for the course An Introduction to Precision Medicine. The practicals use R and Quarto to demonstrate how to prepare clinical data, develop prognostic models, and assess model performance.

Practical materials

The materials are organized as a short learning path:

  1. Data preparation and exploration — inspect the dataset, summarize variables, and explore relationships between predictors and the outcome.
  2. Model development — fit logistic regression models, investigate non-linearity, and compare model performance.
  3. Model validation — evaluate apparent, bootstrap, cross-validation, split-sample, and external validation approaches.

Each topic includes a learner-facing practical and a solution document.

Getting started

Before starting, install R and RStudio. The practical pages list the R packages required for each topic and include code blocks that can be copied directly into RStudio.

The example data are stored in data/dataset.rds. The practicals assume a binary outcome with a common follow-up window; when those assumptions do not hold, a time-to-event analysis may be more appropriate.
